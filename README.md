# 🌱 Farming Friend

Farming Friend is a web application designed to help farmers with **crop-wise farming guidance, weather information, and an online fertilizer store**. The platform also includes a **distributor system** for managing products and orders.

## 🚀 Features

* 🌾 Crop-wise farming guidance
* 🌦️ Weather information
* 🛒 Fertilizer & agricultural product store
* ➕ Add products to cart
* 💳 Checkout system
* 🔐 User authentication
* 👨‍🌾 Farmer and Distributor roles
* 📦 Distributor dashboard
* ➕ Add and manage products
* 📋 Order management
* 📱 Responsive user interface

## ▶️ How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/patilarun93230-tech/Farming-Friend.git
```

### 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 3. Start the Frontend

```bash
npm run dev
```

### 4. Install Backend Dependencies

Open another terminal:

```bash
cd backend
npm install
```

### 5. Start the Backend

```bash
npm run dev
```

## 🌐 Application Modules

### 👨‍🌾 Farmer Module

Farmers can:

* View crop guidance
* Check weather information
* Browse agricultural products
* Add products to cart
* Proceed to checkout
* Manage their account

### 🏪 Distributor Module

Distributors can:

* Access the Distributor Dashboard
* Add new products
* Manage existing products
* View and manage orders

## 🔐 Authentication

The application implements user authentication and **role-based access** for farmers and distributors.

User information such as login status and role is maintained on the client side for the current implementation.
